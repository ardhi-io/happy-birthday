# Birthday website for Abang Ed

A mobile-first 12-slide birthday scrapbook made with HTML, CSS, and JavaScript.

## Add the song
The website is set up for **“Ruang Baru” — Barsena Besthandi**.
To enable the music button, place an MP3 file that you are allowed to use in this folder and name it exactly:

`ruang-baru.mp3`

The audio file is intentionally not included. The website cannot play music from a Spotify link directly; use an MP3 you have permission to host. The visitor starts playback by tapping the music button.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `README.md`, the `assets` folder, and (after adding it) `ruang-baru.mp3`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/ (root)**, then Save.
6. Wait for GitHub Pages to publish your site. The public URL will appear in the Pages section.

## Edit the wording
All birthday messages are in `index.html`. Search for the text you want to change. Keep the `assets/...` file paths unchanged unless you also rename the corresponding image files.
